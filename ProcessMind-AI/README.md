# ProcessMind AI

## Overview

ProcessMind AI is an AI-powered Business Process Automation platform that transforms Standard Operating Procedures (SOPs) into executable workflows using Artificial Intelligence.

## Technology Stack

- Java 21
- Next.js
- TypeScript
- PostgreSQL
- Google Gemini AI
- Docker
